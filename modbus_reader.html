Modbus Reader

Desktopowa aplikacja napisana w Pythonie służąca do komunikacji z urządzeniami wykorzystującymi protokół Modbus TCP. Program umożliwia konfigurację połączenia, odczyt różnych typów rejestrów, interpretację danych oraz prezentację wyników w graficznym interfejsie użytkownika.

Python PyQt6 pymodbus Modbus TCP TCP/IP JSON
Zobacz kod na GitHub Wróć do portfolio

Cel projektu

Celem projektu było stworzenie prostego narzędzia desktopowego pozwalającego na szybki odczyt danych z urządzeń komunikujących się przez Modbus TCP bez konieczności korzystania z konsoli lub zewnętrznych narzędzi diagnostycznych.

Aplikacja została wyposażona w graficzny interfejs użytkownika, umożliwiający konfigurację parametrów połączenia oraz wykonywanie odczytów w czytelny sposób.

Najważniejsze funkcje

  • Połączenie z urządzeniem przez Modbus TCP
  • Konfiguracja adresu IP, portu i timeoutu
  • Obsługa Slave ID
  • Odczyt Holding Registers, Input Registers, Coils oraz Discrete Inputs
  • Wybór adresu i długości odczytu
  • Obsługa formatów UInt16, Int16, UInt32, Int32 i Float32
  • Skalowanie odczytanych wartości
  • Prezentacja wyników w tabeli
  • Zapis i wczytywanie konfiguracji
  • Jasny i ciemny motyw interfejsu
  • Interfejs w języku polskim, angielskim i niemieckim

Architektura

Aplikacja została podzielona na część odpowiedzialną za interfejs użytkownika, konfigurację połączenia oraz komunikację Modbus.

GUI → ustawienia połączenia → pymodbus → Modbus TCP → urządzenie → odczyt rejestrów → interpretacja danych → tabela wyników

Konfiguracja aplikacji przechowywana jest również w pliku JSON.

Technologie

  • Python — logika aplikacji
  • PyQt6 — interfejs graficzny
  • pymodbus — komunikacja Modbus TCP
  • TCP/IP — komunikacja sieciowa
  • JSON — zapis konfiguracji

Czego nauczył mnie projekt

  • Praktycznej obsługi protokołu Modbus TCP
  • Komunikacji aplikacji z urządzeniami automatyki przez sieć Ethernet
  • Obsługi różnych typów danych przechowywanych w rejestrach Modbus
  • Tworzenia interfejsu graficznego w PyQt6
  • Organizacji większej aplikacji Pythonowej na kilka modułów
  • Diagnostyki problemów z komunikacją sieciową i konfiguracją urządzeń
